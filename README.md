# GRNS 28-Day Plan landing page

This is the full source of the page live at https://integratehealthco.com/grns.

Preview this copy: https://masgothard.github.io/grns-landing-page/

## What's in here

- `index.html` is the whole page. Text, styles and images are all inside this one file.
- `legal/` holds the terms, privacy, medical disclaimer and results disclaimer pages the footer links to.

## How to edit it

1. Click **Fork** (top right) to get your own copy.
2. Open `index.html` in your copy and click the pencil icon to edit. Or download it and open it in any code editor.
3. To check your changes, download the file and open it in your browser.

Tip: the file is large because the images are built in. The easiest way to make changes is to give the file to Claude or ChatGPT and describe what you want changed.

## How to send it back

**Option 1 (preferred):** in your fork, click **Contribute** then **Open pull request**. Add a short note on what you changed. Mason will see every edit line by line.

**Option 2:** click **Code** then **Download ZIP** on your fork and send the ZIP to Mason.

Please don't rename `index.html` or move the `legal/` folder, so the links keep working.
